## 🔀 Algorithm Selection Framework

> *The mental model I use when approaching any new problem*

```mermaid
flowchart TD
    A([New Problem]) --> B{Input Type?}
    B -->|Array or String| C{Need all combos?}
    B -->|Tree or Graph| D{Directed?}
    B -->|Intervals| E[Sort and Sweep Line]
    B -->|Numbers| F{Optimise value?}
    C -->|Yes| G[Backtracking]
    C -->|No| H{Subarray or window?}
    H -->|Fixed size| I[Sliding Window]
    H -->|Variable| J{Sorted?}
    J -->|Yes| K[Two Pointers]
    J -->|No| L[HashMap and Prefix]
    D -->|Yes| M{Has cycles?}
    D -->|No| N[DFS and BFS]
    M -->|Possible| O[Topological Sort]
    M -->|No| P{Shortest path?}
    P -->|Weighted| Q[Dijkstra or Bellman-Ford]
    P -->|Unweighted| R[BFS]
    F -->|Yes| S{Overlapping sub-problems?}
    S -->|Yes| T[Dynamic Programming]
    S -->|No| U[Greedy]
    style A fill:#1a1a2e,stroke:#00d9ff,color:#fff

    style I fill:#1a1a2e,stroke:#00c896,color:#fff
    style Q fill:#16213e,stroke:#ffd700,color:#fff
```
